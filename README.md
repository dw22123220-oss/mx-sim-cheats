# MX Simulator Cheats

A collection of cheat mods for MX Simulator including roll resistance reduction, speed boost, and grip boost.

## Features

- **Roll Resistance Cheat**: Reduces bike roll resistance for easier handling
- **Speed Boost**: Increases top speed and acceleration
- **Grip Boost**: Improves tire grip and traction

## Installation

1. Copy the `cheats.lua` file to your MX Simulator mods directory
2. Enable the mod in-game through the mods menu
3. Use the hotkeys to toggle each cheat on/off

## Hotkeys

- `F1`: Toggle Roll Resistance Cheat
- `F2`: Toggle Speed Boost
- `F3`: Toggle Grip Boost

## Configuration

Edit the values in `cheats.lua` to adjust cheat intensity:

```lua
ROLL_RESISTANCE_MULTIPLIER = 0.5  -- Lower = less roll resistance
SPEED_BOOST_MULTIPLIER = 1.3      -- Higher = faster speed
GRIP_BOOST_MULTIPLIER = 1.2       -- Higher = more grip
```

## How It Works

- **Roll Resistance**: Multiplies the bike's roll resistance value, making it easier to maintain momentum
- **Speed Boost**: Increases engine power and velocity for faster acceleration and top speed
- **Grip Boost**: Improves tire grip and traction for better cornering and control
